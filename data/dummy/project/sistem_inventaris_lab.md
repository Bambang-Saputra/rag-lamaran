# Sistem Inventaris Lab

## Latar belakang
Peminjaman alat di laboratorium masih dicatat di buku, sehingga sering ada alat yang tidak jelas siapa peminjamnya.

## Solusi
Aplikasi web untuk mencatat peminjaman dan pengembalian alat, lengkap dengan status stok dan riwayat peminjam.

## Peran saya
Membangun backend REST API dengan FastAPI, mendesain skema database PostgreSQL, dan membuat fitur notifikasi keterlambatan lewat email.

## Hasil
Dipakai oleh laboratorium jurusan selama satu semester untuk sekitar 150 alat. Waktu pengecekan stok mingguan turun dari sekitar 2 jam menjadi 20 menit.

## Teknologi
Python, FastAPI, PostgreSQL, SQLAlchemy, Docker
