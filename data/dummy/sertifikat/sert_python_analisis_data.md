Sertifikat Kelulusan: Python untuk Analisis Data

Diberikan kepada Raka Pratama oleh Akademi Data Nusantara, Maret 2024. Durasi 40 jam.

Materi: dasar Python, manipulasi data dengan Pandas dan NumPy, data cleaning, exploratory data analysis (EDA), visualisasi dengan Matplotlib dan Seaborn, studi kasus analisis penjualan retail.
Proyek akhir: dashboard analisis penjualan bulanan dari dataset transaksi 50.000 baris.
